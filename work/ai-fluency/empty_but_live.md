# Portfolio Deployment: Empty but Live

This document details the portfolio's hosting setup, the live URL, and the steps to activate GitHub Pages for your repository.

---

## 1. Stack & Hosting Configuration
- **Stack:** Semantic HTML5, Vanilla CSS3 (curated Outfit/Inter dark-mode design system).
- **Hosting Provider:** GitHub Pages (free, secure static site hosting directly from the repository).
- **Repository Source:** `VenkataVishnuVardhanReddy/Flyrank` (main branch).

---

## 2. Deployed Live URL
The portfolio research paper has been written to `index.html` at the root of your repository and is served directly at:
> **[https://venkatavishnuvardhanreddy.github.io/Flyrank/](https://venkatavishnuvardhanreddy.github.io/Flyrank/)**

---

## 3. How to Enable GitHub Pages (One-Time Activation)

To make the URL live, execute these three simple steps on GitHub:
1. **Open Settings:** Go to your repository page on GitHub: `https://github.com/VenkataVishnuVardhanReddy/Flyrank` and click the **Settings** tab (the gear icon on the top right).
2. **Configure Pages:** In the left sidebar, scroll down to the "Code and automation" section and click on **Pages**.
3. **Save Source:** Under **Build and deployment**, set the Source dropdown to **Deploy from a branch**.
   - Under **Branch**, select `main` and the root folder (`/root`).
   - Click **Save**.

*Note:* GitHub will take 1–2 minutes to build the site. Once complete, your academic research paper and priority action playbooks will be reachable by anyone worldwide on both desktop and mobile!
