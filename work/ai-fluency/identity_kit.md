# Portfolio Identity Kit & Style Guide

This document outlines the visual identity system, custom typography, color palette, and the standing instructions for Claude to maintain styling consistency.

---

## 1. Typography & Typeface

We use a clean, geometric sans-serif stack to maintain an academic and highly modern technical feel:
- **Heading Font:** `Outfit` (sans-serif, geometric, weight 700/800 for high-contrast headers).
- **Body Font:** `Inter` (sans-serif, highly legible, weight 300/400/500 for prose and tables).
- **Monospace Font:** `JetBrains Mono` (for code snippets, metrics logs, and reason codes).

---

## 2. Color Palette

The palette is a high-contrast, mathematically calm dark-mode system:
- **Primary Background:** `#0f172a` (Sleek slate dark-blue; keeps the page silent so the work is loud).
- **Primary Text:** `#f8fafc` (Near-white slate; highly readable against slate background).
- **Secondary Text / Muted Borders:** `#94a3b8` (Muted slate; used for captions, borders, and metadata).
- **Accent Color (Action CTA):** `#818cf8` (Indigo glow; pulls the eye directly to the "Book a Demo" CTA).
- **Highlight Color (Telemetry):** `#38bdf8` (Sky blue; highlights metrics, charts, and positive signal checks).
