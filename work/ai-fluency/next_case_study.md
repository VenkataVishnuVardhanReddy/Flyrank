This document details the operational checklist to add future project cases, names the next target perception safety research case, and provides the reminder logs to keep the portfolio fresh.

## 1. Step-by-Step Checklist: How to Add the Next Case Study

To maintain visual and narrative consistency, reuse the existing Claude Project context and follow these steps:

1. **Activate the Claude Project:** Open the designated workspace project containing your Voice Card and Style Note.
2. **Initiate the Interview:** Prompt Claude:
   > *"I need to draft a new case study. Interview me one question at a time to extract: (1) The specific safety or ML problem, (2) the engineering decisions/rejected alternatives, and (3) the quantitative metrics and outcome. Keep my academic, rigorous voice."*
3. **Format the 3-Beat Story:** Organize the output using the established structure:
   - **Problem:** The constraint, risk, and base rate.
   - **What I Did:** The implementation, data contracts, and validation splits.
   - **Outcome:** The final precision metrics and code repository links.
4. **Deploy:** Open `index.html`, add a new grid card under the `<main>` cases grid, commit the code, and push to main. GitHub Pages will serve the updated content in under 2 minutes.
